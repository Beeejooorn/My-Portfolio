Project overview

Quotely is a web application for organizing client quotations in one workspace. It brings quotation creation, reusable services, status tracking, and follow-ups together so the current state of each quote is easier to see.

Key features

01

Build and manage quotations

Create quotations with client details, services, pricing, and terms, then review saved quotes.

02

Reuse services and packages

Keep frequently used services available when preparing a new quotation.

03

Follow up with clients

See quotations that need a response and open the related quote from the dashboard.

04

Track status

View quotations by their current draft, sent, pending, approved, or rejected state.

05

See what needs attention

Dashboard totals, a quotation timeline, and upcoming expiration dates give an overview of the workspace.
